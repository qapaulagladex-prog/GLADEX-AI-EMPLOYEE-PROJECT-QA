# GLADEX AI EMPLOYEE PROJECT — QA

Repository for Gladex's new in-house apps and landing pages (built with the QA / AI-employee workflow).
One folder per app.

## Apps
- **alagang-gladex/** — Alagang Gladex after-travel client care landing page (ALEX assistant, hotline, FAQs, reviews). Open `alagang-gladex/index.html`.
  - Status: FAQ complete; interactive parts (ALEX chat, inquiry form, reviews) are still a scripted demo — not yet for public client release.
- **gladex-project-monitor/** — Gladex Project Monitor: tracks all projects per AI employee, with board/dashboard, requests, and reports. Open `gladex-project-monitor/index.html`.
  - Note: the live app uses a shared online database (projects/requests/reports/team). This is the page code; a fresh deploy starts with an empty database.
